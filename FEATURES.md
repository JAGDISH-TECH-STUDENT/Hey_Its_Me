# Features

## Core
- **React 19 + TypeScript + Vite** – modern stack with fast HMR and optimized production builds
- **Fully typed** – TypeScript interfaces for translations, form data, projects, skills, testimonials, and blog posts
- **PWA ready** – `manifest.json` + service worker for offline caching
- **SEO optimized** – meta description, keywords, Open Graph, Twitter Cards

## Visual & UX
- **Dark / Light mode** – toggle with CSS custom properties and smooth transitions
- **Animated gradient background** – radial gradient animation applied globally across all sections
- **Loading screen** – branded initial loader
- **Responsive design** – mobile hamburger menu, fluid grids, and adaptive spacing
- **Smooth scroll** – `scroll-behavior: smooth` with fixed header offset

## Language & Content
- **English / Hindi switcher** – context-based i18n with `LanguageContext`
- **Auto-rotating hero tagline** – typing animation cycles through roles:
  - English: `Full Stack Developer` / `Software Developer`
  - Hindi: `फुल-स्टैक डेवलपर हूँ` / `सॉफ्टवेयर डेवलपर हूँ`

## Sections
- **Hero** – profile photo with gradient border fallback, greeting, typing tagline, and CTA buttons
- **About** – bilingual bio with tech stack pills
- **Skills** – categorized progress bars (Frontend, Backend, Tools) with hover animations
- **Experience** – work history cards with highlights
- **Projects** – GameZone and Homigo cards with live links and tech badges
- **Blog** – article preview cards with date, read time, and category tags
- **Testimonials** – client reviews with quote styling and star ratings
- **GitHub / Social Links** – GitHub, LinkedIn, and LeetCode profile buttons
- **Resume Viewer** – embedded PDF viewer modal with prev/next navigation and no download/print/edit controls
- **Contact Form** – validated form with EmailJS integration

## Integrations
- **EmailJS** – contact form sends directly to email without backend
- **react-pdf** – renders resume as canvas pages inside a custom modal
- **react-icons** – consistent iconography across sections
